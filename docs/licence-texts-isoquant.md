### Notes

- **`packaging.txt`** is dual-licensed: its `LICENSE` file only points at the two real
  texts, so the Apache-2.0 and BSD-2-Clause texts are appended below it here.
- **`r-logger.txt`** follows CRAN's `MIT + file LICENSE` convention, where the shipped
  `LICENSE` file carries only the copyright year and holder. Those values are combined
  with the standard CRAN MIT body.
- **`isoquant.txt`** and **`isoquant-gpl-2.0.txt`** were taken from the pinned IsoQuant
  submodule rather than fetched over the network, so they match the build that ships in
  the container exactly.
- Licence texts for the remaining components were fetched from each project's default
  branch, which tracks the current release rather than the specific version resolved by
  the container build. For MIT/BSD/Apache components this affects only copyright year
  ranges.
