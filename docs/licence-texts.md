### Notes

- **`subread.txt`** was taken from a GitHub mirror of Subread 1.6.1, because Subread is
  released from SourceForge (https://subread.sourceforge.net/) rather than a public git
  host. The text is the unmodified GNU GPL v3; it differs from `GPL-3.0.txt` only in
  that the four fsf.org / gnu.org URLs it contains are the older `http://` forms.
- **`fastqc.txt`**, **`hisat2.txt`** and **`multiqc.txt`** are the full GNU GPL v3 text
  as distributed by those projects, differing from `GPL-3.0.txt` only in URL scheme and
  whitespace.
- **`pyarrow.txt`** is Apache Arrow's `LICENSE.txt`: the Apache-2.0 text followed by the
  project's own appendix of bundled-component licences.
- Licence texts were fetched from each project's default branch, which tracks the current
  release rather than the specific version pinned in the pipeline. For MIT/BSD/Apache
  components this affects only copyright year ranges.
