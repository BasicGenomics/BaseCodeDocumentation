# Downstream analysis

The output from the BaseCode Processing Pipeline can be used for downstream analyses, such as isoform quantification and differential expression.

## BaseCode IsoQuant Pipeline

Performs isoform quantification and differential expression analysis. See [BaseCode IsoQuant Pipeline](isoquant.md).

> **NOTE** The BaseCode IsoQuant Pipeline adapts the output files for IsoQuant automatically. Other downstream analyses may still require minor formatting or preprocessing of the output. If you need help with this, please reach out to us.
