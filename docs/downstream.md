# Downstream analysis

The output from the BaseCode Processing Pipeline can be used for downstream analyses, such as isoform quantification and differential expression.

## IsoQuant

[IsoQuant](https://github.com/BasicGenomics/IsoQuant_pipeline) is a tool for isoform quantification and differential expression analysis.

> **Note:** The output may require minor formatting or preprocessing to be compatible with downstream tools. This is automatically handled by the pipeline.
