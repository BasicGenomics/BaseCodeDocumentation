# Vignettes

Standalone guides for additional analyses and tasks that build on pipeline output, such as
working with the result files, visualisation, and other downstream questions.

## Available vignettes

| Vignette | Applies to | Covers |
| --- | --- | --- |
| [Splitting a BAM by sample](vignette-split-by-sample.md) | BaseCode Processing Pipeline | one BAM per sample from the `SM` tag, with a downloadable script |
| [Filtering full-length molecules](vignette-full-length.md) | BaseCode Processing Pipeline | a high-confidence set of molecules with both ends observed (`TC` and `FC`), with a downloadable script; checking the count against the run report |
| [Viewing reads by tag in IGV](vignette-igv-tags.md) | BaseCode Processing Pipeline, BaseCode IsoQuant Pipeline | colouring, grouping and sorting molecules by tag in IGV |
